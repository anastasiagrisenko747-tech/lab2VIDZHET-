# TravelBoard — Панель путешественника

Интерактивная адаптивная панель управления виджетами. Проект выполнен на HTML, CSS и обычном JavaScript с использованием ES-модулей, классов и `localStorage`.

## Возможности

- **Список дел:** добавление задач, отметка выполнения, удаление.
- **Погода:** текущая погода в Берлине — температура, ощущаемая температура, влажность и ветер.
- **Курсы валют:** актуальный курс EUR к USD и дата курса.
- Добавление, сворачивание и удаление виджетов.
- Нельзя добавить один тип виджета дважды.
- Независимая загрузка данных, индикатор загрузки, обработка ошибок и повторный запрос.
- Сохранение виджетов, состояния сворачивания и задач в `localStorage`.
- Адаптивная сетка для компьютеров и телефонов.

## Как запустить в Visual Studio Code

1. Распакуйте архив проекта.
2. Откройте папку `traveler-dashboard` в Visual Studio Code.
3. Установите расширение **Live Server** (если оно ещё не установлено).
4. Нажмите правой кнопкой мыши на `index.html`.
5. Выберите **Open with Live Server**.
6. Страница откроется в браузере.

Также можно запустить локальный сервер из терминала в папке проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

> Не рекомендуется открывать `index.html` двойным щелчком (`file://`): браузеры могут блокировать загрузку ES-модулей. Используйте локальный сервер.

## Используемые API

1. **Open-Meteo** — `https://api.open-meteo.com/v1/forecast`  
   Получение текущей погоды по координатам Берлина. API-ключ не требуется.  
   Документация: https://open-meteo.com/en/docs

2. **Frankfurter** — `https://api.frankfurter.dev/v1/latest?base=EUR&symbols=USD`  
   Получение курса евро к доллару США. API-ключ не требуется.  
   Документация: https://frankfurter.dev/

Запросы выполняются независимо друг от друга. Если один API недоступен, остальные виджеты продолжают работать.

## Где используется ООП и модули

- `UIComponent.js` — базовый класс карточки с общими кнопками и методом `destroy()`.
- `ToDoWidget.js`, `WeatherWidget.js`, `CurrencyWidget.js` — классы виджетов, наследующие `UIComponent`.
- `Dashboard.js` — класс управления добавлением, удалением и сохранением виджетов.
- `main.js` — точка входа, импортирует класс панели и подключает кнопку добавления.
- Каждый JS-файл использует `export` и `import`.

3. «Проверь адаптивность панели на ширине 375 px и исправь переполнение элементов».
